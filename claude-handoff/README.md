# X500 — חבילת הקוד ל־Claude Code

החבילה מבוססת על קבצי ה־Pi שהועלו ב־14.10.2026. היא כוללת קוד מקור ותצורות, פרומפט מעודכן וממצאים מבדיקת הקוד.

## שימוש

1. חלץ את תוכן החבילה בתיקייה המקומית של `Shahar373/x500-shahar`. אם כבר נוצר קוד בריפו, שמור אותו; אין בחבילה הוראה למחוק אותו.
2. פתח Claude Code בתיקיית הריפו.
3. העתק את כל התוכן של `CLAUDE_PROMPT.md` לתוך Claude Code. בקש ממנו לקרוא גם את `PI_CODE_REVIEW.md` ואת הקבצים שבתיקיית `pi-reference`.

## תוכן

- `pi-reference/current/` — הסקריפטים והתצורות הנוכחיים, לפי נתיבי ההתקנה המקוריים.
- `pi-reference/history/` — גיבויי `.bak` וקובץ תצורת SITL; חומר רקע בלבד.
- `PI_CODE_REVIEW.md` — מה נמצא בקוד ומה כדאי לתקן לפני שילוב בתוכנה.
- `CLAUDE_PROMPT.md` — משימת הבנייה המלאה, כולל ממשק Windows, וידאו ומתקין.
- `SNAPSHOT_INFO.json` — תיעוד הכיסוי, השינויים לצורך ניקוי והבדיקות המקומיות.

## מצב הקבצים

כתובת תחנת הקרקע, כתובת שער המודם, שם המשתמש בנתיבי הבית ומזהה ה־USB המדויק הוחלפו בסמנים. נשמרו כתובת loopback וכתובת בדיקת האינטרנט הציבורית. אין צורך לעלות לריפו את הארכיון המקורי.

**אלה קבצי ייחוס לפיתוח. אין להעתיק אותם ישירות אל `/etc`, `/opt` או `/usr/local` על ה־Pi:** חלק מהתצורות כוללות סמנים במקום פרטים מקומיים, ובקוד הישן קיימות נקודות שדורשות תיקון.

הבדיקה כאן הייתה בדיקת קוד ותחביר בלבד. לא הופעלו הסקריפטים, לא התחברנו לרחפן ולא נבדקו טלמטריה, שירותים או וידאו בזמן אמת.
